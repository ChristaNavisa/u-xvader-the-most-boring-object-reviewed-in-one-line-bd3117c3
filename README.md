One funny, true line reviewing the dullest everyday object I could name: the
tea towel. Its whole job is drying dishes — and it has been wet since Tuesday.

The program writes the review to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), one line, 65 characters, no trailing
newline — the file holds exactly the review and nothing else.
